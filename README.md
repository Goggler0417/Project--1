# Tagmark Local – v9 수정 반영본

현재 개발 중인 최신 Local 버전의 HTML 단일 파일입니다.

반영 사항:
1. artist:, series:, language: 태그의 텍스트형 표시
2. 태그 관리에서 카테고리별 태그 분리
3. 북마크/등장인물 태그 철자순 정렬
4. 등장인물 나이 제거, 성별 라디오 버튼, 사전등록 태그 선택/추가
5. character:, cast: 태그 및 노란색 표시
6. 메인 페이지 카테고리 표기에서 최상위 카테고리 숨김
7. 사전등록 태그 종류 선택을 체크박스로 변경
8. 새 태그의 실제 북마크 사용량 집계 수정

데이터는 브라우저 IndexedDB에 저장됩니다.
