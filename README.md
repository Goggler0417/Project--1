# Tagmark Local — UI update

Base: latest `index(1).html`.

This build includes the requested UI/data changes:
- Artist / Series / Language are shown on bookmark cards as title-like information lines only when the corresponding tags exist.
- All tags remain rounded chips in tag management, editors, and character tags.
- Character / Cast chips use a restrained cyan/teal color.
- Tag-kind registration uses aligned radio buttons.
- Bookmark card URLs are no longer displayed or expandable; the URL remains available in the editor and the Open button.
- Character editor has no age field and uses gender radio buttons.
- Character tags can be selected from registered tags or registered as new tags.
- Character/Cast registered tags may optionally store a linked Series; adding that character tag automatically adds the linked Series tag to the bookmark.
- Tags are alphabetically sorted.
- Category display hides only the top-level category name while retaining lower-level paths.
